# Workflow variables
These are the variables are used by the workflow.

Set during web form configuration:
- clientName (text field): Client full name
- clientEmail (text field): Client email
- agreementName (text field): Agreement title
- agreementId (text field): Agreement reference ID
- projectName (text field): Project name
- packageName (dropdown): Starter / Standard / Premium
- price (number field): Contract value
- repoName (text field): Repository name
- intakeNotes (long text field): Additional onboarding notes
- readyToKickoff (boolean): Readiness check


Set as starting variable during workflow configuration:
- developerName (constant): Internal notification name
- developerEmail (constant): Internal notification recipient
